# Logic Prototype

Build a tiny interactive terminal app when the open question concerns a state model, transition, data shape, or business rule.

1. State the exact question in one paragraph.
2. Use the repository's runtime and package manager.
3. Put the logic behind a small pure reducer, state machine, or function interface.
4. Keep terminal I/O in a thin shell that renders current state and available actions on one screen.
5. Add one repository-native run command.
6. Let the user drive edge cases, then record the answer.
7. Delete the shell; only promote validated logic after rewriting it to production standards.

Do not connect production data, generalize beyond the question, or add a test suite to throwaway UI. If the question is visual, use [UI.md](UI.md).
