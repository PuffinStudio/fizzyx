# diagnose

Use this before changing code for a bug.

1. Reproduce the failure.
2. Capture the exact command, input, and output.
3. Form one hypothesis at a time.
4. Verify the hypothesis with the smallest useful check.
5. Fix the root cause.
6. Re-run the failing check and the nearest regression suite.
